    Fix: re-run `terraform init -upgrade` to select/lock provider ~> 6.0, then plan + apply.

DESIGN DECISION: Dropped the planned "networking" (VPC) module.
  Verified via AWS docs (configuration-vpc-internet.html, configuration-vpc.html):
